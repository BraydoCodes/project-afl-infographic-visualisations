# project-afl-infographic-visualisations
A project that is a continuation (and improvement!) of some of my previous university work. This is about infographic/graph filled posters creating in RStudio and using credited AFL data sources.

The datasets I worked with in this repository include:
- AFL Dataset sourced on Kaggle [URL required]

## SETUP
To view the visualisation and create your own personalised visualisation, use the `setup.R` file to run the whole project, you can add your own data analysis files `.R` files.

There are plans to turn this into a R Shiny Application, however editting your `setup.R` file will allow you to customise the Year and Team that the visualisation focuses on, ensure that you read the comments on the script to ensure that they are valid.
